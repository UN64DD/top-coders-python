# top-coders-python

A repository for learning Python, focused on competitive programming skills.

## Topics Covered

- **Basics** — Hello World, strings, numbers, and formatting
- **Arithmetic** — float vs integer division, remainders
- **User Input** — reading and converting input
- **Booleans & Logic** — comparisons, `and`/`or`

## Getting Started

Run any script directly:

```bash
python helloworld.py
```

Make sure you have Python 3 installed on your system.
